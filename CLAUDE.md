# Рекомендации по анализу датасета Retail Price

## 1. Структура работы

### Фаза 1: Исследовательский анализ данных (EDA)
- Загрузка и первичный осмотр данных (`head`, `info`, `describe`)
- Анализ пропусков и выбросов
- Распределения переменных
- Корреляции между переменными

### Фаза 2: Подготовка данных
- Обработка пропусков (исключение или заполнение)
- Выявление и обработка выбросов
- Кодирование категориальных переменных
- Нормализация/стандартизация числовых признаков при необходимости

### Фаза 3: Моделирование
- Выбор целевой переменной (признак для предсказания)
- Разделение data на train/test
- Выбор и обучение модели (регрессия или классификация)
- Оценка качества модели

## 2. Основные переменные в датасете

- **Целевые признаки** (возможные):
  - `total_price` - общая стоимость
  - `unit_price` - цена за единицу
  - `product_score` - оценка продукта

- **Предикторы**:
  - `qty` - количество
  - `freight_price` - стоимость доставки
  - `product_weight_g` - вес продукта
  - `product_photos_qty` - количество фото
  - `customers` - число покупателей
  - Temporal: `month`, `year`, `weekday`, `weekend`, `holiday`
  - Конкурентные переменные: `comp_1`, `comp_2`, `comp_3`, `ps1-ps3`, `fp1-fp3`

- Визуализировать коррелляции через `sns.heatmap()` для корреляционной матрицы

## 5. Возможные модели для прогнозирования

В зависимости от выбраной целевой переменной:
- **Регрессия**: Linear Regression, Ridge, Lasso, Random Forest Regressor, Gradient Boosting
- **Классификация** (если целевая переменная бинарная): Logistic Regression, Random Forest, XGBoost
- **Временной ряд** (если использовать временные характеристики): ARIMA, Prophet, LSTM

## 6. Метрики оценки

### Для регрессии:
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² (Coefficient of Determination)

### Для классификации:
- Accuracy
- Precision, Recall, F1-score
- ROC-AUC
