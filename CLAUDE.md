# Контекст проекта

## Актуальная версия

Курсовая работа анализирует статистические связи общей цены товара с тремя признаками: числом покупателей (`customers`), ценой третьего конкурента (`comp_3`) и весом товара (`product_weight_g`). Актуальный план — `PLAN.md`; итоговый текст — `coursework.tex`; воспроизводимый расчёт — `science_work_simple.ipynb`.

`science_work.ipynb` содержит архивный расширенный анализ. `OtherSolutions/` содержит сторонний учебный ноутбук и архивный обзор; эти материалы не задают методы и выводы текущей курсовой.

## Модель и проверка

- Используй одну логарифмическую регрессию МНК: `ln(total_price) ~ ln(customers) + ln(comp_3) + ln(product_weight_g)`.
- Данные: 676 наблюдений по 52 товарам за 2017–2018 годы; стандартные ошибки сгруппированы по `product_id`.
- Для коэффициентов используй двусторонние t-проверки, p-value и 95%-ные кластерные доверительные интервалы; для совместной проверки — кластерно-устойчивый F-тест.
- Основные значения: `R² = 0,257`; `F(3, 51) = 46,45`; коэффициенты факторов — `0,541`, `0,526` и `0,126`; статистическая значимость веса на уровне 5% не подтверждена (`p = 0,090`, интервал включает ноль).

## Границы выводов

- Говори о статистических связях, не о причинном влиянии.
- Не называй `total_price` полной ценой с доставкой: в данных она приблизительно соответствует `unit_price × qty`, а `freight_price` хранится отдельно.
- Не утверждай, что модель прогнозирует цену или находит оптимальную цену: текущая работа решает задачу статистического вывода.
- Не трактуй отсутствие статистической значимости веса как доказательство отсутствия связи.
- Не добавляй альтернативные модели, ML-прогнозирование или новые тесты без отдельного запроса.
