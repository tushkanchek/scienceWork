# Оформление курсовой — 03.11.2026

Приоритет для титульного листа — предоставленный образец `example/КУРСОВАЯ РАБОТА.docx`. Для основного текста использованы правила оформления из ГОСТ 7.32–2017: формат страницы, поля, абзацы, интервалы, нумерация, заголовки и подписи. Этот стандарт относится к отчётам о научно-исследовательской работе; его применение к курсовой здесь служит основой оформления и не заменяет отдельные требования кафедры. Утверждённая методичка кафедры в проекте не представлена.

## Титульный лист

Подключается командой `\input{titlepage.tex}` из `coursework.tex`. Самостоятельно `titlepage.tex` собирать не нужно.

По DOCX-образцу перенесены последовательность и выравнивание блоков:

- ведомство и полное название университета — по центру, полужирным;
- институт и кафедра — прописными буквами по центру;
- направление 02.03.01 «Математика и компьютерные науки» и профиль «Наука о данных» — слева;
- «КУРСОВАЯ РАБОТА» и тема — по центру, тема полужирная прописными;
- курс, группа и даты — слева; фамилия студента справа на строке группы, фамилия руководителя справа на строке учёной степени;
- «Казань – 2026» — внизу по центру, год курсивом.

Размер шрифта на титульнике — 14 пунктов Word (14 bp в TeX). Указаны Кибардин М. О., группа 05-308, 3 курс; руководитель — Салимов Р. Ф., канд. физ.-мат. наук. Параметры темы, курса, группы, фамилий, степени и года собраны в начале `titlepage.tex`. Даты оставлены незаполненными, как в образце. Новая тема короче темы в образце, поэтому занимает две строки вместо трёх; для блока темы сохранено место.

Титульник учитывается как первая страница, номер на нём не печатается. Содержание начинается со страницы 2. Вёрстка DOCX-образца просмотрена после экспорта в PDF; итоговый LaTeX-титульник в PDF пока не проверен.

После уточнения пользователя полужирное выделение верхнего блока с министерством и университетом и темы закреплено явно: в LaTeX через `\textbf`, в Word — отдельным стилем и прямым форматированием символов. Размер оставлен 14 пт, как в образце. Проверенный вид титульника Word — `titlepage_preview.png`; это предварительный просмотр Word-копии, а не результат компиляции LaTeX.

## Основной текст

| Элемент | Настройка |
|---|---|
| Лист | A4, книжная ориентация |
| Основной шрифт | Times New Roman при сборке XeLaTeX и наличии шрифта |
| Размер основного текста | Ровно 14 пунктов Word/PDF (`14bp`); размер `\normalsize` задан явно |
| Межстрочный интервал | Полуторный (`setspace`); шаг обычных строк 21 пункт Word/PDF |
| Поля | Слева 30 мм, справа 15 мм, сверху и снизу 20 мм |
| Абзац | Отступ 1,25 см, без дополнительного промежутка между абзацами |
| Выравнивание текста | По ширине |
| Номера страниц | Арабские цифры внизу по центру, сквозная нумерация |
| Структурные заголовки | «СОДЕРЖАНИЕ», «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ», «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» — по центру прописными |
| Главы | С новой страницы, номер без точки и без слова «Глава»; 14 пт, полужирный |
| Подразделы | Нумерация 1.1, 1.2 и т. д.; 14 пт, полужирный; без точки после номера |
| Таблицы | Подпись сверху слева: «Таблица N — Название»; текст таблиц с одинарным интервалом |
| Рисунки | Подпись снизу: «Рисунок N — Название» |
| Приложения | После источников, каждое с новой страницы; буква и название отдельными строками |

Математические формулы используют математический шрифт TeX. Для кода применяется моноширинный шрифт и уменьшенный размер с переносами строк. Уменьшенный текст таблиц, подписей и листингов отличается от основного текста.

Размер основного текста уточнён при повторной проверке: одной опции `14pt` у класса недостаточно для точного совпадения с 14 пунктами Word. Поэтому переопределён `\normalsize`, включая возврат к основному размеру после таблиц и титульника. При базовом шаге `16.8bp` множитель `\onehalfspacing` для этого класса равен 1,25, что даёт `21bp`. Реализация сверена с исходниками [extsizes](https://tug.ctan.org/macros/latex/contrib/extsizes/size14.clo) и [setspace](https://raw.githubusercontent.com/latex-package-repositories/setspace/main/setspace.sty).

## Как получить нужный шрифт

В редакторе выберите **XeLaTeX**; Times New Roman должен быть установлен именно в среде, где собирается документ. Два прохода нужны для содержания и перекрёстных ссылок:

```bash
xelatex -interaction=nonstopmode -halt-on-error coursework.tex
xelatex -interaction=nonstopmode -halt-on-error coursework.tex
```

Если шрифт не найден, документ использует Liberation Serif и выдаёт предупреждение `Times New Roman not installed`. Это позволяет открыть документ с заменой шрифта, но не подтверждает оформление Times New Roman. Если нет и замены, сборка останавливается с сообщением о необходимости установить шрифт.

Совместимость с pdfLaTeX сохранена: используются согласованные начертания Computer Modern с кодировкой T2A и явным предупреждением о замене шрифта. Прежний `mathptmx` убран: в предоставленном `чек_ориг.pdf` использовались подставленные кириллические шрифты, а полужирное выделение не отображалось. Этот режим не даёт Times New Roman; для совпадения с образцом используйте XeLaTeX с установленным Times New Roman.

После сборки проверьте титульник на одной странице, отсутствие переполнений, содержание, таблицы, подписи и переходы к приложениям. Здесь PDF курсовой не собирался согласно договорённости о самостоятельной сборке пользователем.

Полученный от пользователя `чек_ориг.pdf` просмотрен отдельно: 40 страниц, текст извлекается, незаполненных ссылок `??` и текста за пределами листа не обнаружено. Выявлены потеря кириллического полужирного начертания и дополнительные переносы в названии института из-за другой гарнитуры. Этот PDF не включает последние редакционные уточнения и не является проверкой новой версии после изменения шрифтового режима. Нужна повторная сборка текущего `coursework.tex`.
