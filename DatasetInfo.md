# Данные и выбор признаков

Версия от 30.10.2026. Источник — Retail Price Optimization на Kaggle: https://www.kaggle.com/datasets/suddharshan/retail-price-optimization.

CSV содержит 676 наблюдений по 52 товарам, 9 категориям и 20 месяцам: январь 2017 — август 2018. Ключ — `product_id` и преобразованная дата `month_year`. Панель несбалансирована. Пропусков, полных дубликатов и повторов ключа не найдено; все строки сохранены.

## Словарь и роли

| Столбец/группа | Смысл и решение |
|---|---|
| `product_id` | Идентификатор товара; группа для ошибок и разделения обучения/проверки |
| `product_category_name` | Категория; восемь индикаторов, база `garden_tools` |
| `month_year` | Месяц наблюдения; формат `%d-%m-%Y` |
| `total_price` | Отклик, рабочая трактовка — суммарная стоимость продаж товара за месяц; логарифмируется |
| `qty` | Количество проданных единиц; исключено из регрессии из-за почти арифметической связи с откликом |
| `unit_price` | Цена единицы; исключена по той же причине |
| `freight_price` | Доставка; исходная шкала, один ноль допустим |
| `product_name_lenght` | Длина названия; описательный аудит, вне основной спецификации |
| `product_description_lenght` | Длина описания; описательный аудит, вне основной спецификации |
| `product_photos_qty` | Число фотографий; исходная шкала |
| `product_weight_g` | Вес в граммах; натуральный логарифм |
| `product_score` | Рейтинг; исходная шкала, диапазон 3,3–4,5 |
| `customers` | Число покупателей по названию поля; одинаково внутри каждой категории и месяца, поэтому не считать подтверждённым числом покупателей отдельного товара; логарифмируется |
| `weekday`, `weekend`, `holiday` | Календарные показатели; вне основной спецификации |
| `month`, `year` | Согласованы с датой; используются для проверки периода |
| `s` | Смысл не подтверждён; исключён |
| `volume` | Показатель объёма; единица в доступном описании не подтверждена, логарифмируется |
| `comp_1`, `comp_2`, `comp_3` | Конкурентные ценовые показатели; логарифмы, подробное сопоставление конкурентов не документировано |
| `ps1`, `ps2`, `ps3` | Рейтинговые показатели конкурентов; вне основной спецификации |
| `fp1`, `fp2`, `fp3` | Доставка конкурентов; вне основной спецификации |
| `lag_price` | Предыдущая цена; вне основной задачи, требует временного подхода |

В `results/column_audit.csv` есть тип, пропуски, уникальные значения, диапазон и число товаров с временными изменениями для всех 30 исходных полей. Уточняющее описание источника получить не удалось; неизвестную валюту и единицу объёма не приписываем.

## Проверка смысла отклика

Для 643 из 676 строк относительное расхождение `total_price` и `unit_price × qty` меньше 0,3%; максимум — 3,058%. Поэтому `total_price` трактуется как денежная сумма продаж за товар–месяц. Это вывод по структуре данных с оговоркой о неполном описании источника, а не подтверждённый аудит исходных транзакций. Доставка не добавляется.

Вес, объём, рейтинг и число фотографий постоянны внутри товара. Их коэффициенты описывают различия между товарами. `customers` постоянен внутри всех 154 наблюдаемых сочетаний категории и месяца; зависимости между товарами могут быть сильнее, чем допускает кластеризация только по товару. В основной M3 временных эффектов нет; в дополнительной проверке включены 19 индикаторов календарных месяцев. Их включение не снимает предпосылку о независимости ошибок разных товарных групп.

## Модели

M1: шесть прежних факторов — покупатели, три цены конкурентов, вес и фотографии. M2: M1 плюс категория. M3: M2 плюс рейтинг, объём и доставка; девять числовых факторов, 18 коэффициентов с константой. M3q добавляет один квадрат центрированного логарифма покупателей только для диагностики.

Незначимость рейтинга и доставки не используется как основание их удаления. Максимальный VIF в M3 равен 7,158 у первого конкурента; данные не позволяют объявить все факторы независимыми. Матрицы имеют полный ранг. Полные результаты — в `results/`, интерпретация — в `coursework.tex` и `summary.md`.

## Проверка предсказаний

Пять частей разделены по товарам. Категории присутствуют в обучении каждой части. Обычный GroupKFold не обеспечил покрытие категорий, поэтому товары распределены внутри категорий с фиксированным seed 20261030 без обращения к отклику. Проверка оценивает исключённые товары известных категорий при доступных признаках того же периода; она не оценивает будущее и новые категории.

## Календарная чувствительность

В дополнительной M3 с 19 индикаторами конкретных календарных месяцев (37 коэффициентов, те же 676 строк и 52 товарные группы) совместное p-value конкурентов равно 0,061, а p-value веса после Холма — 0,116. Это проверка чувствительности, добавленная после рецензирования: значимость основной M3 не сохраняется на уровне 5% при учёте времени. Неотклонение гипотезы не доказывает отсутствие связи; календарное расширение не объявляется автоматически лучшей моделью.
