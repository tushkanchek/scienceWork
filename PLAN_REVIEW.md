# Разбор образца и обоснование нового плана

Дата: 30.10.2026. Образец: [КУРСОВАЯ РАБОТА.docx](<example/КУРСОВАЯ РАБОТА.docx>), работа о связи характеристик заёмщика с вероятностью дефолта. Изучены содержание, основной текст и код в приложениях. Это анализ структуры и методических решений; воспроизводимость чужих численных результатов без исходных данных не проверялась.

## Что полезно перенести

В образце две главы: «Предварительный анализ данных» и «Основной этап исследования». Сначала описаны данные, распределения и связи, затем гипотезы, регрессия, диагностика, интерпретация и качество прогноза. Теория вводится непосредственно перед её применением. По содержанию введение начинается на странице 3, заключение — на 26, литература — на 28; далее идут приложения.

Сильные стороны структуры:

- Есть самостоятельный предварительный анализ с графиками и конкретными наблюдениями.
- Отдельно рассматриваются связи без контроля других факторов и результаты многофакторной модели.
- Обсуждаются величина связи, доверительные интервалы и статистическая значимость.
- Модель проверяется, а качество на обучении отделяется от качества вне обучения.
- Работа завершается содержательными ответами, а не только таблицей коэффициентов.

Наш прежний план уже содержал корректные элементы: множественную регрессию, интервалы, совместный тест, VIF и кластеризацию. Слабость была в глубине исследования: сравнение конкурентов занимало центральное место, диагностика ограничивалась кратким графиком остатков, категории исключались ради простоты, оценка переноса на новые товары отсутствовала.

## Что в образце нельзя принимать безоговорочно

1. **Незначимость не подтверждает правильность модели.** В разделе 2.3 написано, что проверено, что модель задана правильно. Несколько незначимых проверок позволяют лишь сказать, что конкретные нарушения не обнаружены. В таблице взаимодействий отмечены две несошедшиеся модели; их p-value нельзя использовать как надёжное основание для общего вывода об отсутствии взаимодействий.
2. **Ненормальность признаков не определяет весь выбор методов.** В образце из тестов Шапиро–Уилка выводится необходимость ранговых методов. Выбор должен учитывать проверяемую гипотезу и устройство наблюдений. Для нашей линейной регрессии нормальность исходных признаков не требуется.
3. **Проверка калибровки не гарантирует надёжность прогнозов.** После p = 0,76 в тесте Хосмера–Лемешова сделан слишком сильный вывод о доверии прогнозным вероятностям. Сам по себе высокий p-value не доказывает хорошую калибровку. Кроме того, обычная калибровка критерия не переносится автоматически на совокупность прогнозов из разных обученных моделей.
4. **Повторные разбиения зависимы.** В коде отбора признаков стандартная ошибка разности AUC рассчитана как стандартное отклонение по 25 разбиениям, делённое на корень из 25. Обучающие выборки пересекаются, поэтому трактовать эти разности как независимые наблюдения нельзя без дополнительного обоснования.
5. **Отбор и оценка требуют разделения.** Образец полезно сравнивает отбор по всей выборке с отбором внутри обучения. Но вывод «отбор не ухудшил прогноз» слишком опирается на почти равные показатели первого варианта. В нашем плане нет автоматического отбора по всей выборке перед оценкой качества.
6. **Результаты ограничены проверенными моделями.** Отсутствие выигрыша у одной настройки бустинга не доказывает, что линейной формы достаточно вообще. В нашей работе диагностика также не будет представляться доказательством окончательно правильной модели.

## Адаптация методов

| Элемент образца | Решение для нашей работы |
|---|---|
| Бинарный дефолт и логистическая регрессия | Непрерывный денежный отклик, логарифмическая множественная линейная регрессия |
| Манна–Уитни, хи-квадрат, доли и интервалы Уилсона | Не копировать: другой тип отклика и зависимые повторные строки |
| Корреляции и графики по группам | Сохранить как описательный анализ; категории сравнивать в регрессионной модели |
| Отношение правдоподобий | Кластерный критерий Вальда для нужных коэффициентов/блоков |
| Поправка BH по многочисленным проверкам | Поправка Холма для девяти индивидуальных коэффициентов основной модели; явно определить семейство |
| Много проверок взаимодействий | Одна содержательная проверка кривизны и анализ чувствительности к товарам |
| Отношения шансов и предельные эффекты вероятности | Процентная интерпретация логарифмических коэффициентов с интервалами |
| ROC–AUC, Брайер, матрица ошибок | RMSE и MAE на шкале логарифма, сравнение с прогнозом среднего |
| Стратификация по бинарному исходу | Разделение по товарам с проверкой покрытия категорий в обучении |
| Большое приложение с кодом | По новому пожеланию пользователя: приложения А–Д после литературы и отдельный исполняемый ноутбук |

Для линейной регрессии с повторными наблюдениями товаров используется [кластерная ковариация statsmodels](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.RegressionResults.get_robustcov_results.html). Для разделения товаров — принцип непересекающихся групп, реализованный в [GroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html); покрытие редких категорий проверяется отдельно. Для поправки Холма — [multipletests](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html). Дата обращения: 30.10.2026.

## Почему предложенный объём умеренный

По дополнению к плану основная модель содержит девять числовых факторов (шесть прежних плюс рейтинг, объём и доставка) и один категориальный блок: 18 коэффициентов с константой при полном ранге. Модель с шестью факторами и категориями сохраняется как обязательное сравнение. В образце основная модель содержит 32 коэффициента и константу, а дополнительно используются отбор, многочисленные взаимодействия, бустинг и бутстрэп. Здесь таких расширений нет.

Усложнение сосредоточено на пяти содержательных задачах: изучение дополнительных признаков, учёт категории, аккуратная проверка нескольких коэффициентов, устойчивость оценок и проверка ошибки вне обучения. Все этапы отвечают конкретному исследовательскому вопросу. При этом 52 товара, а не 676 независимых объектов, ограничивают точность анализа; особенно осторожны выводы по двум категориям с двумя товарами каждая.

## Ключевое уточнение по нашим данным

Повторное чтение CSV подтвердило 676 строк и 52 товара. Для 643 строк относительное расхождение между `total_price` и `unit_price × qty` меньше 0,3%. Поэтому прежняя формулировка «общая цена товара» недостаточно точна: рабочая трактовка — суммарная стоимость продаж товара за месяц. Перед реализацией нужно свериться с описанием источника и уточнить смысл `customers` и конкурентных цен. Это уточнение меняет интерпретацию результатов, но сохраняет тему множественной регрессии и выбранный отклик.
