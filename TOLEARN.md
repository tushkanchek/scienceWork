# Что нужно понимать для курсовой и защиты

Для защиты достаточно уверенно объяснить следующие пункты.

## 1. Задача и данные

- Вопрос работы: какие цены трёх конкурентов связаны с общей ценой отдельно и сохраняются ли эти связи, когда цены учтены одновременно.
- В данных 676 наблюдений по 52 товарам за 2017–2018 годы.
- Средняя общая цена — около 1423, медианная — около 808; среднее выше медианы.
- В моделях используются число покупателей, цены `comp_1`, `comp_2`, `comp_3` и вес товара.
- Выводы описывают связь; причинное влияние эта модель не доказывает.

## 2. Регрессия

- МНК подбирает коэффициенты так, чтобы сумма квадратов ошибок была как можно меньше.
- Сначала сравниваются три модели, в каждой из которых есть цена только одного конкурента, число покупателей и вес. Затем оценивается одна модель со всеми тремя ценами конкурентов одновременно.
- В логарифмической модели коэффициент приблизительно показывает процентную связь при изменении признака на 1%, если остальные признаки фиксированы.
- `R² = 0,298` означает, что расширенная модель описывает около 29,8% разброса логарифма цены в этой выборке; это не оценка точности прогноза на новых данных.

## 3. Проверка коэффициентов

- Нулевая гипотеза: коэффициент равен нулю, то есть модель не обнаруживает связи с этим признаком.
- При уровне значимости 5% коэффициент считают статистически значимым, когда `p-value < 0,05`.
- 95%-ный доверительный интервал, который не включает ноль, согласуется с таким выводом.
- p-value — не вероятность того, что нулевая гипотеза верна. Это вероятность получить такие же или более экстремальные данные при условии, что она верна.
- В расширенной модели общий F-тест проверяет все пять коэффициентов, а отдельный групповой F-тест — три цены конкурентов. Результаты: `F(5, 51) = 28,73`, `p < 0,001`; `F(3, 51) = 10,58`, `p < 0,001`. Совместная значимость группы не означает значимость каждого её коэффициента.

## 4. Почему учитываются товары

Одни и те же товары встречаются в данных в разные месяцы, поэтому их наблюдения могут быть похожи. Кластерные стандартные ошибки по товару учитывают эту зависимость при оценке неопределённости коэффициентов. В анализе 52 товарные группы.

## 5. Сравнение моделей

В трёх моделях с одним конкурентом коэффициенты положительны и значимы:

| Модель | Коэффициент цены конкурента | p-value | Скорректированный `R²` |
|---|---:|---:|---:|
| Только `comp_1` | 0,364 | 0,0134 | 0,236 |
| Только `comp_2` | 0,669 | 0,000028 | 0,286 |
| Только `comp_3` | 0,526 | 0,00048 | 0,254 |

`comp_2` даёт наибольший скорректированный `R²` среди этих вариантов на данной выборке. Это не доказывает, что он всегда лучший или точнее прогнозирует новые наблюдения.

## 6. Расширенная модель

- Число покупателей: `β = 0,543`, `p < 0,001`, 95%-ный интервал `[0,428; 0,658]`.
- `comp_1`: `β = 0,035`, `p = 0,802`, интервал `[-0,245; 0,315]`; индивидуальная связь не подтверждена.
- `comp_2`: `β = 0,532`, `p = 0,011`, интервал `[0,125; 0,939]`; положительная индивидуальная связь подтверждена.
- `comp_3`: `β = 0,228`, `p = 0,253`, интервал `[-0,168; 0,624]`; индивидуальная связь не подтверждена.
- Вес товара: `β = 0,135`, `p = 0,037`, интервал `[0,008; 0,262]`; в расширенной модели значимость на 5% подтверждена.
- Три цены конкурентов связаны умеренно между собой (корреляции логарифмов около 0,436–0,582). Поэтому отдельные модели и расширенная модель отвечают на разные вопросы: связь без учёта других конкурентных цен и условная связь при их фиксации.
- Не говори, что незначимые `comp_1` и `comp_3` «не влияют»: данных недостаточно, чтобы подтвердить их отдельную связь после учёта остальных факторов.

При увеличении значимого фактора на 10% точечная модельная оценка составляет примерно 5,3% для числа покупателей, 5,2% для `comp_2` и 1,3% для веса, при прочих равных. Это не причинные эффекты.

## 7. Графики

- На графике коэффициентов точки показывают оценки, а горизонтальные линии — 95%-ные интервалы; для `comp_1` и `comp_3` интервалы включают ноль, для `comp_2` — нет.
- График остатков — только визуальная проверка; неодинаковый разброс не заменяет формальный тест.

## 8. Ограничения

Модель включает пять факторов, охватывает ограниченный период и не доказывает причинность. Кластерные стандартные ошибки учитывают повторные наблюдения при статистической проверке, но не заменяют модель с индивидуальными эффектами товаров. Сравнение моделей выполнено на одной выборке.
