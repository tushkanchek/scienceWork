## Смысл работы

### Что делаем и зачем

Работа посвящена **применению аппарата математической статистики** к прикладной задаче — моделированию цены товара в электронной коммерции.

Задача ставится не как «обучить предсказательную модель» (что было бы темой для курса machine learning), а как **статистическое исследование**:

1. Построить оценки параметров регрессионной модели методом наименьших квадратов (МНК).
2. Изучить **статистические свойства** этих оценок: несмещённость, эффективность, распределение.
3. Проверить все **предпосылки классической линейной модели** с помощью формальных тестов.
4. Построить **доверительные интервалы** и провести **проверку гипотез** о значимости факторов.
5. Сравнить асимптотический и ресэмплинговый (bootstrap) подходы к статистическому выводу.
6. Применить альтернативные методы оценивания при нарушении предпосылок МНК.

### Почему это ценно для кафедры математической статистики

- Работа охватывает **ключевые темы курса**: оценивание, проверка гипотез, доверительные интервалы, асимптотическая теория, ресэмплинг.
- Прикладная часть показывает **умение применять теорию** к реальным данным, а не только к учебным примерам.
- Каждый шаг сопровождается **статистическим обоснованием**: почему применяем именно этот тест, какова нулевая и альтернативная гипотезы, что означает p-value в данном контексте.
- Сравнение методов (МНК vs WLS vs Ridge vs Huber; асимптотика vs bootstrap) демонстрирует **понимание свойств оценок**, а не только навык запуска готовых функций.

### Исследовательские вопросы

1. Какие факторы статистически значимо влияют на общую цену товара `total_price`?
2. Выполняются ли предпосылки классической линейной модели на данных Retail Price?
3. При каких нарушениях предпосылок МНК-оценка теряет оптимальность, и какие альтернативы это компенсируют?
4. Насколько совпадают асимптотические и bootstrap-доверительные интервалы для коэффициентов регрессии в условиях данной выборки (n = 676)?

### Глава 1. Теоретические основы множественной линейной регрессии

**1.1 Модель и обозначения**
- Матричная запись: Y = Xβ + ε
- Предпосылки классической линейной модели (Gauss-Markov + нормальность)

**1.2 Оценка МНК**
- Вывод оценки из задачи минимизации суммы квадратов остатков
- Явная формула: β̂ = (X'X)⁻¹X'Y
- Геометрическая интерпретация (проекция на столбцовое пространство X)

**1.3 Свойства МНК-оценки**
- Несмещённость: E[β̂] = β
- Ковариационная матрица: Var(β̂) = σ²(X'X)⁻¹
- Теорема Гаусса-Маркова: МНК = BLUE
- Распределение при нормальности ошибок: β̂ ~ N(β, σ²(X'X)⁻¹)
- Связь МНК с методом максимального правдоподобия (MLE)

**1.4 Статистический вывод**
- t-тест значимости отдельного коэффициента: t = β̂ⱼ / SE(β̂ⱼ) ~ t(n−k)
- F-тест значимости модели в целом
- F-тест вложенных моделей (сравнение полной и редуцированной)
- Доверительные интервалы для коэффициентов
- Доверительные и предсказательные интервалы для прогноза

**1.5 Качество подгонки**
- Коэффициент детерминации R²
- Скорректированный R²
- Информационные критерии AIC, BIC

### Глава 2. Диагностика предпосылок регрессионной модели

**2.1 Нормальность остатков**
- Графический анализ: гистограмма, Q-Q plot
- Тест Шапиро-Уилка
- Тест Колмогорова-Смирнова
- Тест Жарка-Бера

**2.2 Гомоскедастичность**
- Графики остатков vs предсказанные значения
- Тест Бройша-Пагана
- Тест Уайта
- Тест Гольдфельда-Квандта

**2.3 Независимость ошибок (автокорреляция)**
- Статистика Дарбина-Уотсона
- Тест Бройша-Годфри

**2.4 Мультиколлинеарность**
- Матрица корреляций предикторов
- Фактор инфляции дисперсии (VIF)
- Condition number матрицы X'X

**2.5 Выбросы и влиятельные наблюдения**
- Стьюдентизированные остатки
- Leverage (диагональ hat-матрицы)
- Расстояние Кука
- DFFITS, DFBETAS

### Глава 3. Методы оценивания при нарушении предпосылок

**3.1 Взвешенный МНК (WLS)** — при гетероскедастичности
- Модель с неоднородной дисперсией
- WLS-оценка и её свойства

**3.2 Ridge-регрессия** — при мультиколлинеарности
- Функционал с L2-регуляризацией
- Смещённость при меньшей дисперсии (bias-variance tradeoff)
- Выбор параметра λ через кросс-валидацию

**3.3 Lasso-регрессия** — для отбора признаков
- L1-регуляризация и разреженные решения
- Сравнение с Ridge

**3.4 Робастная регрессия Хубера** — при наличии выбросов
- Функция потерь Хубера
- M-оценивание как обобщение МНК и метода наименьших модулей

### Глава 4. Ресэмплинговые методы статистического вывода

**4.1 Идея bootstrap**
- Эмпирическое распределение оценки
- Pairs bootstrap и residual bootstrap — когда какой применим

**4.2 Bootstrap-доверительные интервалы**
- Percentile CI
- BCa (bias-corrected and accelerated) CI
- Сравнение с асимптотическими t-интервалами

**4.3 Bootstrap при нарушении предпосылок**
- Поведение bootstrap при ненормальных ошибках
- Wild bootstrap при гетероскедастичности

**4.4 (Опционально) Monte Carlo исследование**
- Генерация искусственных данных с известным β
- Сравнение фактического покрытия асимптотических и bootstrap-CI
- Изучение поведения МНК vs WLS vs Ridge vs Huber при разных типах нарушений

## Ключевые инструменты

**Python-стек:**
- `numpy`, `pandas` — данные
- `scipy.stats` — статистические тесты
- `statsmodels` — регрессия с полной статистикой (коэффициенты, SE, p-значения, тесты, диагностика)
- `scikit-learn` — Ridge, Lasso, Huber, кросс-валидация
- `matplotlib`, `seaborn` — визуализация

**Почему `statsmodels`, а не только `sklearn`:** для статистического вывода нужны стандартные ошибки коэффициентов, p-значения, диагностические тесты. `sklearn` ориентирован на предсказание и этого не даёт, а `statsmodels` — как раз классический статистический пакет.

## Критерии успеха работы

1. **Теоретическая глава** изложена корректно и полностью: вывод МНК, свойства оценки, теорема Гаусса-Маркова, распределение β̂, тесты.
2. **Каждый применённый метод** сопровождается формулировкой нулевой и альтернативной гипотез, теоретической статистикой теста, её распределением при H₀.
3. **Диагностика предпосылок** проведена в полном объёме, результаты корректно интерпретированы.
4. **Альтернативные методы** применены обоснованно — именно там, где обнаружены соответствующие нарушения.
5. **Bootstrap-CI** построены и сопоставлены с асимптотическими; различия обсуждены.
6. **Прикладные выводы** сформулированы в терминах предметной области (какие факторы важны для ценообразования), но опираются на строгие статистические результаты.
