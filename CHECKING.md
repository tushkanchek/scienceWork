# Файлы для проверки курсовой

`coursework_check.docx` — Word-копия актуального `coursework.tex`, подготовленная для загрузки на проверку. Включены титульный лист, содержание, весь основной текст, формулы, таблицы, рисунки, список источников и приложения. Это экспорт формата; содержание исследования и результаты не переписаны. Исходником работы остаётся LaTeX.

В DOCX используются Times New Roman 14 пт, полуторный интервал основного текста и поля 30/15/20/20 мм. Семнадцать отдельных формул и формулы в тексте сохранены как редактируемые формулы Word; семь рисунков встроены. Таблицы и листинги используют уменьшенный шрифт. Отображение Word проверено через временный экспорт LibreOffice; это не сборка PDF из LaTeX. Если Word заменяет отсутствующий шрифт, расположение текста может измениться. После редактирования обновите содержание: щёлкните по нему правой кнопкой → «Обновить поле» → «Обновить целиком».

`coursework_check.txt` — текстовая копия с теми же основными разделами, источниками и кодом. Она не передаёт рисунки и оформление Word; подписи и текст таблиц сохранены, формулы представлены записью LaTeX. Это запасной формат для сервиса, принимающего TXT, а не версия для печати.

## Что загружать

- Студенческий кабинет «Антиплагиата» поддерживает DOCX и PDF с текстовым слоем, а также другие текстовые форматы. Устаревший DOC для загрузки студенческой работы не поддерживается. [Руководство студента](https://docs.antiplagiat.ru/ru/html/structure_student_guide.html).
- Бесплатный личный кабинет принимает PDF с текстовым слоем и TXT; DOCX доступен в платных вариантах. [Руководство частного пользователя](https://docs.antiplagiat.ru/ru/html/private_user_guide.html).
- Требования вашей кафедры могут определять состав файла для проверки. Например, опубликованный регламент КФУ оставляет кафедре право устанавливать требования к включению титульных листов, источников и других элементов. Это не основание самостоятельно удалять части работы. [Регламент КФУ, п. 8.2](https://kpfu.ru/portal/docs/F898175832/Reglament.po.antiplagiatu.pdf).

Оба подготовленных файла содержат полную содержательную часть, библиографию и приложения. Внешняя загрузка и проверка здесь не выполнялись. Процент оригинальности и показатель использования ИИ не измерены; гарантировать прохождение проверки нельзя. Экспорт не маскирует происхождение текста и не подменяет самостоятельное понимание работы. При содержательной доработке следует сохранять ссылки, точно описывать выполненные расчёты и придерживаться требований кафедры к использованию ИИ.

## Пересоздание Word

Нужны Pandoc и `python-docx`. Если Pandoc отсутствует, его можно установить вместе с Python-обёрткой:

```bash
python -m pip install -r requirements_word.txt
python build_word.py
python validate_word.py
```

При отдельной установке Pandoc: `python build_word.py --pandoc /путь/к/pandoc`. Сборщик не устанавливает библиотеки и не загружает работу во внешние сервисы. Он останавливается при предупреждении о неудачной конвертации формул и проверяет текстовые фрагменты в DOCX. `word_export_manifest.json` фиксирует хеши исходников и результатов; `validate_word.py` обнаруживает устаревший экспорт, проверяет формулы, таблицы, рисунки и соответствие кода приложениям.

Для заполнения сохранённых результатов полей номеров страниц сборщик также поддерживает `--preview-pdf /путь/к/просмотру-Word.pdf`. Это должен быть локальный просмотр именно текущей Word-вёрстки; номера после изменений нужно обновлять в редакторе. Без этого параметра поля остаются рабочими и обновляются средствами Word.
