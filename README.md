# Курсовая работа

Тема: **«Линейная регрессия для анализа факторов, связанных с ценой товара»**.

## Основные материалы

- `PLAN.md` — план исследования и структура курсовой.
- `coursework.tex` — текст курсовой работы.
- `science_work_simple.ipynb` — короткий воспроизводимый анализ.
- `presentation_5min.pptx` — презентация на 7 слайдов с графиками к пятиминутному выступлению.
- `presentation_5min.pdf` — PDF-версия презентации для просмотра и печати.
- `presentation_assets/` — фирменная боковая полоса и знаки КФУ/института из образца.
- `speech_5min.md` — текст выступления, согласованный со слайдами.
- `summary.md` и `summary.docx` — развёрнутое резюме результатов.
- `coefficients_ci_simple.png` — коэффициенты полной модели и кластерные 95%-ные интервалы.
- `price_distribution_simple.png` — распределение общей цены до и после логарифмирования.
- `residuals_simple.png` — остатки расширенной модели.
- `build_presentation.py` — сборка презентации из актуальных графиков и результатов.
- `example/` — два PDF-образца оформления курсовой работы и презентации.

`science_work.ipynb` содержит прежний расширенный разбор. Каталог `OtherSolutions/` хранит вспомогательный анализ и не относится к итоговой работе.

Оформление презентации повторяет приложенный образец: белые рабочие слайды с синей боковой полосой и знаками университета, синие титульный и заключительный слайды.

## Что исследуется

Используется датасет Retail Price: 676 наблюдений по 52 товарам за 2017–2018 годы. Целевая переменная — `total_price`; факторы — число покупателей, вес товара и цены трёх конкурентов. Рассматриваются логарифмические регрессии, а стандартные ошибки группируются по товару из-за повторных наблюдений.

Сначала сравниваются три модели, где включена цена одного конкурента. Затем оценивается множественная модель со всеми тремя конкурентными ценами.

## Основные результаты

- В отдельных моделях все три цены конкурентов положительны и значимы при 5%; скорректированный `R²` составляет 0,236 для `comp_1`, 0,286 для `comp_2` и 0,254 для `comp_3`.
- В модели со всеми ценами конкурентов индивидуально значимы число покупателей (`β = 0,543`), `comp_2` (`β = 0,532`) и вес (`β = 0,135`). Для `comp_1` и `comp_3` интервалы включают ноль.
- Цены конкурентов значимы совместно: `F(3, 51) = 10,58`, `p < 0,001`. Общий тест модели: `F(5, 51) = 28,73`, `p < 0,001`; `R² = 0,298`, скорректированный `R² = 0,293`.
- Выводы описывают статистические связи и не доказывают причинное влияние.

## Запуск материалов

Чтобы пересобрать презентацию после изменения графиков или результатов, из каталога `scienceWork/` выполните:

```bash
python build_presentation.py
```

Для сборки PDF курсовой нужны TeX Live и графики PNG из каталога проекта. Ноутбук использует `pandas`, `numpy`, `statsmodels` и `matplotlib`.
