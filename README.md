# Курсовая работа

Тема: **«Линейная регрессия для анализа факторов, связанных с ценой товара»**.

## Основные материалы

- `PLAN.md` — согласованная структура курсовой и выступления, включая описательную статистику и общий F-тест.
- `coursework.tex` — сокращённый текст курсовой в LaTeX.
- `science_work_simple.ipynb` — воспроизводимый анализ с описательной статистикой и двумя графиками.
- `residuals_simple.png` — график остатков для курсовой и презентации.
- `coefficients_ci_simple.png` — оценки коэффициентов с 95%-ными кластерными интервалами.
- `speech_5min.md` — текст выступления примерно на пять минут.
- `presentation_5min.pptx` — слайды к выступлению.
- `summary.docx` — краткое резюме обновлённой работы.
- `TOLEARN.md` — основные понятия и результаты для защиты.

`science_work.ipynb` содержит прежний расширенный анализ. Для сокращённой курсовой используется `science_work_simple.ipynb`.
Каталог `OtherSolutions/` содержит архивный разбор стороннего ноутбука и не входит в итоговую работу.

## Результат сокращённой модели

Оценена одна логарифмическая регрессия по 676 наблюдениям и 52 товарам. Представлены описательные характеристики, индивидуальные проверки коэффициентов и совместный F-тест; стандартные ошибки сгруппированы по товару.

- Число покупателей: коэффициент `0,541`, 95%-ный интервал `[0,419; 0,662]`, `p < 0,001`.
- Цена третьего конкурента: коэффициент `0,526`, интервал `[0,243; 0,809]`, `p = 0,00048`.
- Вес товара: коэффициент `0,126`, интервал `[-0,020; 0,272]`, `p = 0,090` — значимость на уровне 5% не подтверждена.
- `R² = 0,257`.
- Общий кластерно-устойчивый тест: `F(3, 51) = 46,45`, `p < 0,001`.

В `coursework.tex` уже включены оба графика. Для сборки PDF нужны TeX Live и файлы PNG из этой папки; запустите `pdflatex coursework.tex` дважды, чтобы обновились ссылки и оглавление. Ноутбук использует `pandas`, `numpy`, `statsmodels` и `matplotlib`.
