# Курсовая работа

**«Анализ данных розничной торговли с помощью множественной регрессии»**.

Актуальная версия от 30.10.2026: девять числовых факторов и товарная категория, кластерные ошибки по товару, диагностика, анализ чувствительности и пятикратная проверка на исключённых товарах.

## Основные файлы

- `PLAN.md` — согласованная структура исследования.
- `PLAN_REVIEW.md` — разбор нового образца и обоснование адаптации.
- `REVIEW.md` — проверка логики, результатов и оставшихся ограничений.
- `analysis_retail.py` — единый исходный код с разделителями ячеек.
- `science_work_simple.ipynb` — выполненный ноутбук с таблицами и графиками.
- `coursework.tex` — обновлённый отчёт: введение, две главы, заключение, литература, приложения А–Д.
- `results/` — CSV всех результатов и `manifest.json` с версиями, проверками и хешем данных.
- `figures/` — семь актуальных графиков/составных рисунков, используемых в отчёте.
- `report_tables/` — таблицы LaTeX, автоматически полученные из CSV.
- `appendix/` — блоки основного кода, автоматически включаемые в приложения отчёта.
- `build_analysis_materials.py` — формирование ноутбука, листингов и таблиц; сохраняет выполненные ячейки при неизменном исходнике.
- `run_notebook.py` — запуск всех ячеек через локальное ядро Jupyter.
- `requirements.txt` — версии библиотек использованного окружения Python 3.12.
- `DatasetInfo.md` — словарь данных, ограничения и выбор факторов.
- `summary.md` — краткий актуальный отчёт о результатах.
- `presentation_5min.pptx` — 8 основных и 2 скрытых резервных слайда в стиле КФУ; `presentation_5min.pdf` — 8 основных слайдов.
- `speech_5min.md` — соответствующая речь, около 639 слов на 5 минут.
- `defense_guide.tex` — подробное пособие для подготовки к защите: 29 разделов, семь рисунков с разбором, примеры и ответы на вопросы.
- `TOLEARN.md` — порядок подготовки и ключевые факты.

`summary.docx` и старые PNG с суффиксом `_simple` относятся к предыдущему анализу с шестью факторами. Актуальные презентация, речь и учебное пособие уже согласованы с расширенной версией. Источник графиков — `figures/`.

`science_work.ipynb` — архивный расширенный анализ; `OtherSolutions/` — сторонние вспомогательные решения; `example/` — образцы оформления и новая курсовая другого автора.

## Воспроизведение

Запускать команды из каталога, где находится `retail_price.csv`.

```bash
python -m pip install -r requirements.txt
python analysis_retail.py
python build_analysis_materials.py
python run_notebook.py
```

Первая команда устанавливает зависимости. Скрипт анализа создаёт результаты и рисунки, сборщик переносит код в ноутбук и приложения и создаёт таблицы отчёта. Последняя команда выполняет все ячейки ноутбука и сохраняет выводы. Скрипт анализа и ноутбук выполняют одни и те же вычисления; повторный запуск нужен, если требуется сохранить выводы именно в ноутбуке.

Для работы без Jupyter достаточно `python analysis_retail.py` и затем `python build_analysis_materials.py`. Если меняется код анализа, выполнить эту последовательность заново. Для проверки структуры отчёта и согласованности артефактов: `python validate_materials.py`. Независимый пересчёт коэффициентов, ковариации и предсказаний: `python validate_statistics.py`. Презентация, речь и учебное пособие проверяются командой `python validate_defense_materials.py`.

PDF пользователь собирает самостоятельно из `coursework.tex`. Вместе с ним нужны каталоги `figures/`, `report_tables/` и `appendix/`. Используются русский pdfLaTeX, `extreport`, `amsmath`, `booktabs`, `graphicx`, `hyperref` и `fvextra` для листингов с переносами строк. В этом этапе PDF не собирался, поэтому итоговая пагинация и визуальная вёрстка не проверены.

## Результаты

Отклик — логарифм суммарной стоимости продаж товара за месяц, а не цены единицы. Сохранены все 676 строк по 52 товарам и 20 месяцам. Поле `customers` одинаково внутри категории и месяца; точный механизм построения исходных агрегатов не документирован.

M1 содержит шесть факторов; M2 дополнительно учитывает категорию; M3 добавляет рейтинг, объём и доставку. M3 содержит 18 коэффициентов с константой, R² = 0,395, скорректированный R² = 0,379.

В основной M3 цены конкурентов значимы совместно: F(3,51) = 4,100, p = 0,011. После поправки Холма по девяти индивидуальным коэффициентам значимы покупатели и вес; для веса скорректированное p = 0,049, близко к границе. Ни один конкурент индивидуально после поправки не выделяется. Дополнительный блок рейтинга, объёма и доставки: p = 0,151.

RMSE вне обучения на лог-шкале: среднее — 1,199; M1 — 1,043; M2 — 1,030; M3 — 1,033. Расширение не улучшило совокупную ошибку на выбранном разбиении. Это внутреннее сравнение товаров известных категорий при известных признаках тех же периодов, не проверка будущих продаж.

## Презентация и подготовка к защите

Для обновления PPTX после пересчёта результатов: `python build_presentation.py`. Используются текущие CSV и графики; стиль и логотипы взяты из существующей презентации. PDF экспортирован LibreOffice и визуально просмотрен. Он содержит только основные слайды, скрытые резервные остаются в PPTX.

`defense_guide.tex` можно собирать отдельно от курсовой: положите рядом каталог `figures/` с семью PNG. Готовый комплект — `defense_guide_bundle.zip`. Подключаемых таблиц нет; графики подробно разобраны рядом с изображениями. Подробно разобраны смысл отклика, выбор факторов, M1–M3, МНК, кластерные ошибки, t/F, p-value, интервалы, Холм, VIF, проценты, проверка предсказаний и вопросы комиссии. Это учебное дополнение для автора, не замена тексту курсовой. Его PDF здесь не собирался.

## Проверка чувствительности к времени

В дополнительной M3 с 19 индикаторами конкретных календарных месяцев (37 коэффициентов, те же 676 строк и 52 товарные группы) совместное p-value конкурентов равно 0,061, а p-value веса после Холма — 0,116. Это проверка чувствительности, добавленная после рецензирования: значимость основной M3 не сохраняется на уровне 5% при учёте времени. Неотклонение гипотезы не доказывает отсутствие связи; календарное расширение не объявляется автоматически лучшей моделью.

Результаты: `results/time_sensitivity.csv`, `results/time_coefficients.csv`, `results/time_joint_test.csv`. Основное предсказательное сравнение M1–M3 осталось прежним и не относится к будущим периодам.
