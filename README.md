Тема: **«Анализ данных розничной торговли с помощью множественной регрессии»**.

- `coursework.tex` — текст курсовой работы.
- `science_work_simple.ipynb` — воспроизводимый анализ данных, расчёты и графики.
- `presentation_5min.pptx` и `presentation_5min.pdf` — презентация на 8 слайдов.
- `speech_5min.md` — текст выступления, синхронизированный со слайдами.
- `summary.md` и `summary.docx` — саммари результатов и аргументация выбора признаков.
- `DatasetInfo.md` и `TOLEARN.md` — описание данных и заметки для защиты.
- `predictor_correlations_simple.png` — корреляции факторов множественной модели.
- `coefficients_ci_simple.png` — коэффициенты модели и кластерные 95%-ные интервалы.
- `price_distribution_simple.png` — распределение общей цены до и после логарифмирования.

Оформление презентации следует приложенному образцу. Использованы официальный горизонтальный логотип КФУ на титульном и заключительном слайдах и гербовый знак в боковой полосе.

## Что исследуется

Используется датасет Retail Price: 676 наблюдений по 52 товарам за 2017–2018 годы. Целевая переменная — `total_price`. В итоговую множественную модель вошли шесть факторов: число покупателей, цены трёх конкурентов, вес и число фотографий в карточке товара. Число фотографий добавлено как контрольный признак; его индивидуальная значимость не подтверждена.

Проверка данных не выявила пропусков, полных дубликатов или повторов пары «товар—месяц», поэтому сохранены все строки. `unit_price` и `qty` исключены из-за почти механической связи с целевой ценой; `lag_price` почти дублирует `unit_price`. У включённых факторов максимальная парная корреляция равна 0,582, VIF — 1,06–1,84.

Сначала сравниваются три модели с ценой одного конкурента, затем оценивается множественная модель со всеми тремя конкурентными ценами.

## Основные результаты

- В трёх отдельных моделях все цены конкурентов положительны и значимы; скорректированный `R²`: 0,239 для `comp_1`, 0,299 для `comp_2` и 0,258 для `comp_3`.
- В множественной модели индивидуально значимы покупатели (`β = 0,550`), `comp_2` (`β = 0,594`) и вес (`β = 0,152`). Для `comp_1`, `comp_3` и числа фотографий индивидуальная связь не подтверждена.
- Цены конкурентов значимы совместно: `F(3, 51) = 11,24`, `p < 0,001`. Общий тест модели: `F(6, 51) = 23,98`, `p < 0,001`; `R² = 0,311`, скорректированный `R² = 0,305`.
- Выводы описывают статистические связи и не доказывают причинное влияние.

## Запуск материалов

Чтобы пересобрать презентацию после изменения графиков или результатов, из каталога проекта выполните:

```bash
python build_presentation.py
```

Для сборки PDF курсовой нужны TeX Live и графики PNG из каталога проекта. Ноутбук использует `pandas`, `numpy`, `statsmodels` и `matplotlib`.
